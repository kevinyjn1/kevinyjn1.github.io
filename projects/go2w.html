Go2W Motion Capture Pipeline

Reliable pose ground truth is the foundation of any robot learning system. This project builds a low-cost, real-time motion capture pipeline around commodity hardware — Intel RealSense depth cameras and AprilTag fiducial markers — integrated with ROS2 and running on a Unitree Go2W quadruped platform.

Why not a commercial MoCap system?

Vicon and OptiTrack are accurate but expensive, require calibrated spaces, and don't travel well. For a university robotics lab doing outdoor and multi-room experiments, a portable, self-contained system is far more practical. The tradeoff is accuracy (a few mm vs. sub-mm), which is acceptable for the locomotion and manipulation tasks we care about.

Architecture

One or more RealSense D435 cameras publish RGB-D streams as ROS2 topics. An AprilTag detector node estimates 6-DoF poses of tagged objects relative to each camera frame. A multi-camera fusion node (with hand-calibrated extrinsics) merges estimates and publishes a clean pose stream at ~30 Hz. A separate ground-truth recorder node logs synchronized pose + joint-state data for offline replay.

Use cases

  • Providing demonstration ground truth for the YOLH diffusion policy.
  • Evaluating locomotion controllers in structured obstacle courses.
  • Multi-robot swarm experiments where relative positioning matters.

Stack

ROS2 Humble, Intel RealSense SDK, apriltag_ros, Python, Unitree Go2W SDK.
